# Онлайн-деканат — решение кейса «Центр-инвест» (UMIHack 2026, пакет v1.0)

Студент загружает фото/скан (JPG, PNG) или одностраничный PDF и задаёт вопрос.
Сервис распознаёт текст, извлекает поля, проводит предварительную проверку по `rules.md`
и отвечает со ссылками на поля (`field:<ключ>`) и пункты Положения (`rule:N.N`).
Окончательное решение принимает сотрудник деканата (п. 1.3).

## Установка и запуск
```sh
pip install -r requirements.txt
streamlit run app.py                      # интерфейс
python generate_results.py --kit <папка пакета> --out results.json --evaluate
python evaluate.py --reference reference_results.json --predictions results.json
```
`--kit` — папка с `documents.json`, `questions.json` и `documents/`.
`--source auto` (по умолчанию): текстовый слой PDF, если он есть, иначе EasyOCR по PNG;
`--source ocr` — всегда OCR по картинке.

## Файлы
| Файл | Назначение |
|---|---|
| `app.py` | Streamlit-интерфейс, кнопка «Скачать results.json» |
| `ocr.py` | EasyOCR (ru+en) с предобработкой снимка |
| `extractor.py` | поля по ключам v1.0, даты в ISO, подпись/печать по графике |
| `responder.py` | `validation` и `answers` по правилам README |
| `rules.py` | разбор `rules.md`, поиск похожих пунктов (TF-IDF + ключевые слова) |
| `document_types.json` | типы, ключи, подписи полей, пункты Положения (новый тип — без кода) |
| `generate_results.py` | пакетная обработка набора в `results.json` |

## Как это работает
- **Поля** ищутся по подписям в документе («ФИО студента: …»), затем по типичным
  оборотам («Справка выдана …», «с … по …», «№ … от …»). Пустая строка `____` → «не найдено».
- **Даты** `01.09.2026`, `1 сентября 2026 года`, `2026-09-01` → `2026-09-01`.
- **Подпись и печать** — по графике: цветные пиксели (у текста цветность ≈ 15–25,
  у макетов подписи/печати ≈ 70–80) склеиваются в пятна; круглое крупное пятно — печать,
  вытянутый росчерк — подпись. Надписи «Подпись», «М.П.» не учитываются (п. 2.3).
  Не уверены — `false`.
- **Ответы**: комплектность → `value = status`; поле → значение и `field:<ключ>`;
  «кто принимает решение» → `rule:1.3`; остальное → `answerable: false`.

## Зависимости и модели
EasyOCR 1.7.1 (детектор CRAFT и распознаватель для ru/en, веса скачиваются библиотекой при
первом запуске), scikit-learn, Pillow, NumPy, SciPy, pypdf, pypdfium2, Streamlit.
Внешние API для OCR, извлечения и ответов не используются; всё работает локально.
